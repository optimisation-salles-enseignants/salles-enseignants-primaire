# Tableau de bord : salles de classe et enseignants (primaire, Burkina Faso)

Tableau de bord d'aide à la décision pour un directeur régional (Data Challenge Burkina, édition Éducation 2026, défi 3).

- Application : `04_CODE/DASHBOARD/app.py` (Streamlit).
- Données : tables publiques du concours, utilisées uniquement pour le concours (`02_DONNEES/`).
- Lancer en local : `pip install -r requirements.txt`, puis `streamlit run 04_CODE/DASHBOARD/app.py`.
- Détails, limites et sources : `04_CODE/DASHBOARD/README_DASHBOARD.md`.

Les normes (élèves par maître, élèves par salle), les scénarios, les départs et les capacités de construction sont des hypothèses, affichées comme telles dans l'application.
